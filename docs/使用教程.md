# OfferCabin 使用教程

> OfferCabin 是一站式求职 AI Agent，由「桌面端主体 + 浏览器插件」两部分组成。桌面端负责 AI 对话、投递看板、岗位搜索、简历画像、面试复盘；浏览器插件负责网申表单智能填写。本教程覆盖从安装到精通的全流程。

---

## 一、桌面端安装与启动

### 1.1 获取安装包

从官方渠道下载 `OfferCabin-v1.2.0-full.zip`（含桌面端 + 插件 + 快速上手指南）。

### 1.2 安装与启动

1. 将 zip 解压到任意目录（**路径不要含中文或空格**，例如 `D:\OfferCabin\`）
2. 进入解压后的目录，双击 `OfferCabin.exe` 启动
3. 程序会自动打开浏览器到应用首页 `http://localhost:8000/`
   - 若未自动打开，手动在浏览器访问该地址即可
4. 启动后会看到一个控制台窗口（显示运行日志），**关闭它即停止服务**

### 1.3 首次配置 LLM（可选但推荐）

OfferCabin 的 AI 能力依赖大模型。未配置时会自动降级为 Mock 模式（可体验流程但无真实 AI）。

1. 打开应用后，点击侧栏「设置」
2. 在 LLM 配置区填入你的 API Key（支持 GLM-4.5 / DeepSeek / Qwen / GPT-4o 等所有 OpenAI 兼容协议）
3. 点击「连通性测试」确认可用
4. 保存配置

> 💡 支持模型分级：Agent 编排用强模型（GLM-4.5/DeepSeek-V3/GPT-4o），内容生成用快模型（GLM-4-Flash/Qwen-Plus），省钱又高效。

## 二、浏览器插件安装

插件用于网申表单智能填写，在用户已登录的真实浏览器中工作，避免跨域问题。

### 2.1 安装步骤

1. 打开 Chrome 或 Edge 浏览器
2. 地址栏输入 `chrome://extensions` 回车
3. 右上角打开「**开发者模式**」开关
4. 点击「**加载已解压的扩展程序**」
5. 选择安装包内的 `offercabin-extension` 文件夹
6. 工具栏出现 OfferCabin 图标即安装成功

### 2.2 绑定桌面端

插件默认独立工作（本地规则匹配）。若要使用 LLM 增强匹配和画像同步：

1. 先启动桌面端 `OfferCabin.exe`
2. 点浏览器工具栏的 OfferCabin 图标打开弹窗
3. 进入「设置」面板，确认后端地址为 `http://localhost:8000`
4. 进入「画像」面板，点击「从后端同步」
5. 桌面端填好的简历画像会自动同步到插件本地

## 三、核心功能使用

### 3.1 AI 对话（Agent 模式）

应用首页即 AI 对话页。OfferCabin Agent 集成 28 个工具，会根据你的意图自动拆解任务。

**常用话术示例：**

| 你说什么 | Agent 会做什么 |
|---------|---------------|
| 「帮我找北京 AI Agent 岗，要大厂」 | 搜索岗位 → 评估真实性 → 匹配画像 → 加入看板 |
| 「我刚面完字节三面，答得不好」 | 触发面试复盘技能 → 打分 + 改进建议 |
| 「我投了 30 份没回复，怎么办」 | 触发求职策略技能 → 数据诊断 + 建议 |
| 「这个岗位是不是培训贷」 | 触发反欺诈技能 → 5 级风险识别 |
| 「最近投递压力大，很焦虑」 | 触发情绪支持技能 → 共情陪伴 |

直接在输入框打字回车即可，支持流式输出（打字机效果）。

### 3.2 投递看板

路径：侧栏「投递看板」

- **六列状态**：已投递 → 笔试中 → 面试中 → 已录用 / 已拒绝 / 已撤回
- **拖拽切换状态**：按住卡片拖到对应列
- **统计概览**：顶部显示投递数 / 回复率 / Offer 率 / 平均等待天数
- **跟进提醒**：今日待办 / 即将面试 / Offer 到期 / 长期未回复自动高亮
- **导入导出**：支持 CSV 批量导入历史投递记录

### 3.3 岗位搜索

路径：侧栏「岗位搜索」

- 输入关键词 + 城市搜索 Boss 直聘岗位
- **三级降级**：登录态搜索（最准）→ 公开 HTML 页（兜底）→ 模拟数据（演示）
- 搜索结果点「加入看板」一键录入投递记录
- 想用真实搜索：先在浏览器登录 Boss 直聘，再启动桌面端

### 3.4 简历画像

路径：侧栏「简历画像」

- **手动填写**：基本信息 / 教育 / 工作 / 技能 / 项目 / 证书 / 自我总结
- **PDF 一键导入**：上传 PDF 简历，自动解析为结构化画像（LLM 解析，未配 Key 时规则降级）
- **自定义字段**：支持添加任意字段
- 画像会供 Agent 调用，用于简历生成 / 岗位匹配评分 / 智能填表

> 🔒 隐私分层：身份证 / 住址 / 银行卡 / 护照等敏感字段**只存浏览器本地**，后端强制剔除、永不落库。

### 3.5 智能填表（浏览器插件）

1. 在桌面端「简历画像」页填好基本信息
2. 打开任意网申页面（如公司官网投递表单）
3. 点浏览器工具栏的 OfferCabin 图标
4. 插件自动扫描表单 → 匹配画像 → 一键填写
5. 填写结果有颜色标记：**绿色=已填 / 黄色=待确认 / 灰色=跳过**

> 插件不会自动提交表单，填完由你确认后再提交，安全可控。

### 3.6 面试复盘

路径：侧栏「面试复盘」

1. 面试结束后新建记录
2. 填写面试公司 / 岗位 / 轮次 / 表现
3. AI 自动分析：打分 + 亮点 + 不足 + 改进建议
4. 与 Agent 面试辅导技能联动，可继续追问

### 3.7 求职日志与周报

- 侧栏可进入日志页记录每日求职动态
- 一键生成周报：自动汇总本周投递 / 面试 / 进展

### 3.8 主题与外观

路径：侧栏「设置」

- **6 套主题**：纸质档案 / 午夜墨色 / 深林 / 海洋 / 复古 / 极简
- **密度切换**：紧凑 / 标准 / 宽松
- 设置实时生效，无需重启

## 四、常见问题

### Q1：启动后浏览器打不开页面？
A：等 3-5 秒让后端服务起来，手动访问 `http://localhost:8000/`。若仍不行，检查 8000 端口是否被占用。

### Q2：AI 对话没反应 / 回复很奇怪？
A：检查「设置」页 LLM 配置是否正确，点「连通性测试」。未配置 Key 时会降级为 Mock（回复是假数据）。

### Q3：Boss 搜索没有真实数据？
A：需在浏览器登录 Boss 直聘后再用。未登录时会降级到公开页数据或模拟数据，属正常现象。

### Q4：插件填表不准？
A：1) 确认简历画像已填完整；2) 点插件「从后端同步」拉取最新画像；3) 启用后端后可走 LLM 语义匹配更准。

### Q5：换电脑数据怎么办？
A：投递记录和画像存在后端数据库（`data/` 目录），把整个 `OfferCabin` 文件夹拷走即可。敏感信息在浏览器本地，需在新机重新填写。

### Q6：杀毒软件误报？
A：PyInstaller 打包的 exe 偶尔被误报，本程序开源可查，可加入白名单或从源码自行构建。

## 五、卸载

- 桌面端：删除整个 OfferCabin 文件夹即可（绿色软件，无注册表残留）
- 浏览器插件：`chrome://extensions` → 找到 OfferCabin → 点「移除」
- 数据清理：删除 `data/` 目录可清空所有投递记录和画像
