## 0. ⚠️ 备案前必须先决策的三件事（决定整张表怎么填）

### 0.1 主体类型：个人备案 vs 企业备案 —— 强烈建议企业

代码与定位明确含**经营性**特征：
- README：「支持多账号售卖」「账号售卖场景」
- 环境变量 `REGISTRATION_INVITE_CODE`（注册邀请码 = 账号售卖开关）
- 存在 `docs/收款码/`（收款二维码）

→ **非经营性 ICP 备案不允许收费**。若保留账号售卖/收款，须办理**经营性 ICP 许可证（增值电信业务经营许可证-信息服务业务）**，主体须为企业、注册资金 ≥ 100 万。

| 路径 | 主体 | 能否收费 | 额外许可 |
|---|---|---|---|
| 个人备案 | 个人 | ❌ 不可 | 无 |
| 企业备案（非经营） | 企业 | ❌ 不可 | 无 |
| 企业备案 + ICP 证（经营） | 企业 | ✅ 可 | 增值电信业务经营许可证 |

- ⬜ 你选哪条路径：________（建议：企业备案 + ICP 证；或先按企业非经营备案、收费功能暂不上线）

### 0.2 社区广场 = 电子公告/论坛类（高风险，需先处理）

「社区广场」是 UGC 发帖 + 楼中楼评论，性质属**电子公告服务(BBS/论坛)**。工信部对电子公告有专项要求，多数省份**个人备案不允许开办论坛**，企业备案也需接入商严格审核，部分省份要求取得专项审批或先下线该功能。

- ⬜ 处理方式：① 备案期间临时关闭社区广场 ② 保留并接受严格审核 ③ 其他：___

### 0.3 求职招聘内容的前置审批可能性

「投递分享」导流至公司官网招聘入口，内容涉及招聘求职。部分省份管局将求职招聘类归入需前置审批（《人力资源服务许可证》）的范畴。OfferCabin 仅做入口导流、非自行发布岗位，但仍可能被问询。

- ⬜ 是否已咨询接入商是否需前置审批：___

> 另：项目含 LLM 生成式 AI 功能 + UGC，若上线还涉及《生成式人工智能服务管理暂行办法》算法备案、深度合成备案——属 ICP 备案之外的合规层，另行处理。

## 4. 技术概要（备案辅助说明，可直接粘贴）

- 技术栈：Python（FastAPI）+ 原生前端（HTML/CSS/JS）+ Docker；数据库 SQLite / PostgreSQL。
- 部署：单容器同域部署，后端托管前端静态资源；公开服务仅 8000 端口；管理后台 8001 仅绑定 127.0.0.1，不公网暴露。
- LLM：OpenAI 兼容协议（GLM / DeepSeek / Qwen / GPT，可选），未配置时 AI 功能降级为 Mock。
- 开源协议：MIT；官方仓库 https://github.com/TPA2001/OfferCabin
- 隐私：身份证 / 住址 / 银行卡等敏感字段仅存浏览器本地，后端强制剔除不落库。
