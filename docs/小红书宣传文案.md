## 文案 A · 痛点共鸣型（推荐首发）

**标题三选一**
1. 求职季投了 100 份简历，80% 卡在重复填表 😵‍💫
2. 还在手填网申？这个浏览器插件让我每天省 2 小时
3. AI Agent 帮我管求职：从搜岗到面试复盘，一条龙

**正文**

姐妹们，求职季真的崩溃 😭
- 投一个公司填 30 分钟基本信息，下次再投又来一遍
- 面试被问到才发现自己岗位 JD 都没看清
- 投了 100 份不知道进度，第 30 天才想起来跟进

所以我自己撸了一个 **OfferCabin** —— 一站式求职 AI Agent 🦾

它把求职拆成了 6 个技能 + 28 个工具：
- 🧠 **Agent 模式**：直接说"帮我找北京 AI Agent 岗，要大厂"，它自己拆任务、调工具
- 📝 **网申神器**：Chrome 插件扫一遍表单，自动匹配画像，姓名/学校/项目一键填（敏感信息只存你浏览器本地）
- 📊 **投递看板**：6 列状态拖拽，今日待办/即将面试/offer 到期自动提醒
- 🎯 **岗位真实性判断**：5 级风险识别，避开"培训贷/先付费"坑
- 📄 **JD 定制简历**：把岗位描述贴进去，自动生成匹配简历和求职信
- 🎤 **面试复盘**：每场面完让 AI 给反馈，还能量化表达
- 💬 **情绪支持技能**：焦虑/emo 的时候直接聊，不讲大道理

最戳我的是 **隐私分层**：
- 身份证、住址、银行卡 → 永远只在你浏览器本地
- 后端只存基本信息、学历、项目，方便 Agent 跨设备调用
- LLM 调用时 PII 自动脱敏成 `[REDACTED]`

开源 MIT 协议，本地能跑、没网也能用 ✌️
GitHub 搜 **OfferCabin**，B 站教程在路上 🛠️

## 文案 B · 工具罗列型（适合 AI/技术博主）

**标题三选一**
1. 我把求职拆成了 28 个 AI 工具 + 6 个技能，开源了
2. 做 Agent 一年，把求职场景跑通了：6 技能 / 28 工具 / 隐私分层
3. 一个 Chrome 插件 + 一个本地 Agent = 求职全流程自动化

**正文**

做 AI Agent 的尽头，是把自己的痛苦自动化 🤖

OfferCabin = **求职 AI Agent**，4 层架构（API → Orchestration → Features → Platform）：

**Agent 能力**
- 🛠️ 28 工具分 8 组：画像 / 投递 / 看板 / 跟进 / 智能填写 / 投递前准备 / 岗位分析 / Feature
- 📜 6 个声明式技能（SKILL.md）：emotional_support / interview_coach / career_strategy / job_verify / boss_search / smart_fill

**浏览器扩展（V0.0.3 新特性）**
- 扫表单 → 字段提取 → 画像匹配 → 确定性填写
- **新增"从后端同步画像"**：扩展启动自动从后端拉画像合并到本地，零录入开箱即用
- 敏感数据（身份证/住址/银行卡）只存 `chrome.storage.local`

**核心特色**
- Boss 搜索三级降级链：登录态 → 公开 HTML → Mock
- 简历/求职信按 JD LLM 定制
- 面试复盘 + 周报自动生成
- 健康检查面板（数据库 / LLM Provider / 鉴权模式）

**技术栈**
Python 3.10+ · FastAPI · SQLAlchemy 2.0 · 原生 HTML/CSS/JS
LLM Function Calling · Playwright Chromium · PEP 621
GLM-4.5 / DeepSeek-V3 / Qwen / GPT-4o 全兼容

**部署**
- `python run.py` 一键启动（Windows 自动 ProactorEventLoop 修复）
- PyInstaller 单文件打包（无需 Docker）
- 6 套主题 + 紧凑/标准/宽松密度

Star 一下支持下开源 🙏

## 文案 C · 故事型（适合小红书个人号）

**标题三选一**
1. 校招投了 47 家公司后，我做了一个求职 AI Agent
2. 从"投了没回应"到"日均跟进 5 家"，我靠这个 Agent
3. 把求职变成 Agent 流水线后，我多睡了 1 小时

**正文**

校招那阵子，我每天的状态：
- 早上 9 点：刷 30 个 Boss 新岗位
- 上午 11 点：填 3 个网申，每个 30 分钟
- 下午 2 点：投过的公司进度全忘了
- 晚上 8 点：emo，为什么没人理我 😭

然后我意识到——**求职本身就是个 Agent 任务**。

于是一个人的 OfferCabin 诞生了 🦾

**它能干啥？**
- 🗣️ 直接跟它说话："帮我找上海的产品岗，要大厂，不要 996"
  它会自己拆解：搜岗位 → 评估真实性 → 匹配画像 → 加入看板
- 📋 看板 6 列：已投递 → 笔试中 → 面试中 → 已录用 / 已拒绝 / 已撤回
  拖一下改状态，今日待办/即将面试自动弹提醒
- ✍️ 网申神器：装个浏览器插件，扫一下表单自动填
  V0.0.3 新功能：Web 端填的画像，扩展启动自动同步到本地
- 🎤 面试完跟它说"今天面了字节三面，答得不好"
  它会给你打分 + 改进建议 + 生成周报

**最安心的细节**
身份证、住址、银行卡这些，只存我电脑本地，后端永不见。
LLM 调我简历前会自动把手机号、姓名涂掉。

**现在**
- 我每天 9 点花 5 分钟看 Agent 推的 3 个高匹配岗位
- 跟进提醒不会再忘
- 面试复盘有据可循
- 省下的时间……多睡了 1 小时 😴

如果你也累于求职，试试看。
开源 MIT，B 站教程在剪了 ✂️
